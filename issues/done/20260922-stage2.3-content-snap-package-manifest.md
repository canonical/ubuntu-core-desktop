# Stage 2.3 — candidate content-snap package manifest (GNOME)

Date: 2026-09-22 (deliverable of step 2.3 in
`20260922-split-core26-desktop-base-snap.md`)

## Impact / Priority

No user-facing impact — this was a planning deliverable for the
base-snap split: an accurate, source-verified manifest of the 46
declared stage-packages across the three desktop-content parts,
produced as the input for deciding what moves into a content snap.
Impact derived from the original note's symptoms.

## Context

Extracted the full stage-packages list from the three desktop-related
parts of core-base-desktop's snapcraft.yaml. The desktop-content parts
are: desktop-packages, gdm-packages, gnome-desktop-components. The
base-OS parts (chisel-libs, system-setup-tool-packages, locale-packages)
are EXCLUDED — they are core OS / system-setup content, not GNOME
desktop content, and must stay in the base.

NOTE: This is the *raw* current list (no judgement about which packages
should move — just the accurate current list with each package's source
part noted). Transitive dependencies are NOT listed (snapcraft pulls
them; e.g. gnome-settings-daemon pulls python3, systemd pulls
motd-news, etc.). Some entries were deliberately stripped at build time
(pipewire/wireplumber binaries) — see the part comments; the manifest
below is the *declared* stage-packages, not the post-strip prime
output.

CAVEAT for 2.4: gdm3 itself is a display-manager concern (Stage 3A
wants GDM OUT of the base, not merely re-homed into a content snap), so
deciding whether gdm3 belongs in gnome-desktop-content vs its own
display-manager snap is a 2.4 design judgement, not done here.
